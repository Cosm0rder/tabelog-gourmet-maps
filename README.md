# 食べログ全集 → Googleマイマップ（グルメ全集プロジェクト）

食べログの保存リスト1,429店に、百名店（全年度アーカイブ）・The Tabelog Award（全年度）・ミシュランガイド東京/京都・大阪（2026＋過去年）・ゴ・エ・ミヨ2026・La Liste・Asia's/World's 50 Best・Destination Restaurants・OAD・TRYラーメン大賞から集めた名店プールを統合し、**全12,119店**をGoogleマイマップへ一括収録したプロジェクトのデータと記録。

## 自分もやってみたい人へ（GitHubが分からなくてOK）

自分のAI（ChatGPT / Claude / Gemini など）に丸投げするのが一番簡単です。

1. [`つかいかた.md`](つかいかた.md) を開く
2. 中のコピペ用プロンプトを自分のAIに送る
3. AIが [`AI-INSTRUCTIONS.md`](AI-INSTRUCTIONS.md)（AI向け作業指示書）を読み、あなたのGoogleアカウントに4つのマイマップを作成します

軽量版ZIP（CSV38ファイル＋指示書のみ・約220KB）はこちら：
https://github.com/Cosm0rder/tabelog-gourmet-maps/releases/download/v1.0/gourmet-maps-for-ai.zip

## 方法

1. 各ソースから名店リストを収集し、保存済みリストと名寄せ（正規化名＋エリア）して「新規プール」10,690店を構築（`new-pool-unified.tsv`）
2. ジャンルは食べログ百名店の35ジャンル区分に統一
3. Googleマップの通常リストへの1件ずつ追加は、アカウント全体の追加ブロック（約1,000件で発生）に阻まれたため、**ジャンル別CSV → Googleマイマップへ一括インポート**に切替（1レイヤー2,000件・1マップ10レイヤーの制約に合わせ4マップ構成）
4. CSVは `mymaps-csv/`（列：店名／位置検索＝店名＋エリア／出典）。インポートはGoogleドライブ経由でファイルを選ぶのが確実
5. 広義（本体店の支店・姉妹店・別業態）111店は公式店舗一覧で確認し、別レイヤーに収録（`sister-candidates.md`）

## 主なファイル

- `new-pool-unified.tsv` — 統合プール全10,690店（店名・エリア・ジャンル・出典）
- `mymaps-csv/` — マイマップ投入用ジャンル別CSV（保存済み込み全12,119店＋広義111店）
- `make_mymaps_csv.py` / `build_new_pool.py` — CSV生成・プール統合スクリプト
- `sister-candidates.md` — 広義候補111店（ブランド別・公式確認済み）
- `hyakumeiten-raw/` — 百名店 全ジャンル×全年度の生データアーカイブ
- `progress.md` — 作業全記録

## 注意

- 店舗情報は各公式発表・ガイドの公開情報に基づく収集時点のものです。移転・閉店等は含み得ます。
- マイマップ本体は個人アカウント内の非公開マップです。このリポジトリはその再現用データと記録です。
